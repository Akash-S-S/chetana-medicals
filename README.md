# chetana-medicals (Medical Store Management App)

A simple, user-friendly web application for managing a Medical Store. This application helps calculate tablet prices based on sheet prices and helps track patient billing.

## Features

- Input tablet details (name, tablets per sheet, sheet price)
- Real-time calculation of price per tablet
- Real-time calculation of patient bill based on number of tablets
- Store tablet data with automatic price updates for existing tablets
- Responsive design for all device sizes
- Data persistence using localStorage
- Clear form and storage options

## Deployment

This application is ready to be deployed on Vercel. Follow these steps:

1. Install the Vercel CLI (if not already installed):
   ```
   npm install -g vercel
   ```

2. Clone or download this repository

3. Navigate to the project directory and run:
   ```
   vercel
   ```

4. Follow the prompts to complete deployment

Alternatively, you can connect your GitHub repository to Vercel for automatic deployments.

## Project Structure

- `index.html` - The main application file containing HTML, CSS, and JavaScript
- `vercel.json` - Configuration file for Vercel deployment
- `package.json` - Project information and dependencies
- `README.md` - This documentation file

## Local Development

To run the application locally:

1. Clone or download this repository
2. Open `index.html` in your web browser

Alternatively, if you have Node.js installed:

1. Clone or download this repository
2. Run `npm install` to install dependencies
3. Run `npm start` to start a local server
4. Open your browser to the shown URL (usually http://localhost:5000)
